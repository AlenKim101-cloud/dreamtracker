# Dreamspace

A calm, responsive dream journal built with React. Add, edit, search, and filter dream entries, with data saved privately in your browser on the current device.

## Run locally

From the repository root:

```powershell
npm --prefix dreamtracker-app install
npm start
```

The app opens at [http://localhost:3000](http://localhost:3000).

## Other commands

```powershell
npm test
npm run build
```

## Data and privacy

Dream entries are stored in this browser's local storage. They are not synced to an account or backed up to a server. Clearing this browser's site data will remove saved entries.
